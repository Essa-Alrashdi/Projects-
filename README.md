# 📊 Business Intelligence Capabilities & Organizational Agility Analysis

## 🎯 Project Overview
This project analyzes the impact of **BI Capabilities** on **Organizational Agility** using primary data collected via **Google Forms** and processed through **Excel**. The final analysis was performed using **Structural Equation Modeling (SEM)** in **SmartPLS 4**, validating the structural model and path coefficients.
