# 📊 Business Intelligence Capabilities & Organizational Agility Analysis

## 🎯 Project Overview
This repository showcases the practical application of my research on how **BI Capabilities** influence **Organizational Agility**. The data was collected using **Google Forms** and analyzed using **Structural Equation Modeling (SEM)** via **SmartPLS 4**.
